-- ex Schreiben 2 | 괄호 안의 낱말을 알맞은 형태로 바꾸거나 알맞은 낱말을 골라 빈칸에 쓰세요.
gap: Wenn ich reich [=wäre], würde ich viel reisen. (sein) | 내가 부자라면 여행을 많이 할 텐데. => 사실이 아닌 일을 가정할 때는 wäre를 써요.
gap: Das ist das Auto [=meines] Vaters. (mein) | 우리 아버지의 차예요. => 남성 2격은 meines예요.
gap: Das ist die Freundin, mit [=der] ich telefoniere. (die) | 내가 통화하는 친구예요. => mit 뒤에는 3격이 와요.
gap: Die Nachricht [=wurde] gestern gelöscht. (werden) | 그 메시지는 어제 지워졌어요. => 지난 일의 Passiv는 wurde로 만들어요.
gap: Je mehr ich übe, [=desto] besser spreche ich. (desto, als) | 연습을 많이 할수록 말을 더 잘해요. => je 다음에는 desto가 와요.
gap: Der Zug [=war] schon abgefahren. (sein) | 기차는 이미 떠난 뒤였어요. => Plusquamperfekt는 war나 hatte로 만들어요.
gap: Ich helfe einem [=Kollegen]. (Kollege) | 나는 동료 한 사람을 도와요. => Kollege는 1격 단수가 아니면 -n이 붙어요.

-- schreiben Mein Text | 학교 신문에 의견 글을 써요. 주제는 '학교에서 휴대폰을 써도 될까?'예요. 아래 내용을 넣어서 여덟 문장 넘게 써 보세요. 이 글은 자동으로 채점하지 않아요. 다 쓴 뒤에 예시 글과 비교하고 아래 항목을 스스로 확인해요.
punkt: 주제와 내 입장 (Meiner Meinung nach …) ; 근거 (je … desto, deswegen) ; 반대쪽 생각 (Die anderen sagen, dass …) ; 가정해서 말하기 (Wenn ich … wäre, …) ; 제안 (… könnten …) ; 맺는 말
start: Meiner Meinung nach …
muster: Meiner Meinung nach sollten Handys in der Schule erlaubt sein, aber nur in den Pausen. Im Unterricht lenken sie ab. Je öfter ich auf das Handy sehe, desto schlechter kann ich mich konzentrieren. Deswegen brauchen wir Regeln. Die anderen sagen, dass man mit dem Handy auch lernen kann. Das stimmt, obwohl die meisten nur spielen. Wenn ich Lehrerin wäre, würde ich die Handys am Morgen sammeln. In den Pausen könnten die Schüler sie zurückbekommen. So hätten alle mehr Ruhe.
check: 여덟 문장 넘게 썼어요 ; Meiner Meinung nach 바로 뒤에 동사를 썼어요 ; je … desto나 deswegen으로 근거를 댔어요 ; wenn 문장과 뒤 문장에 wäre, hätte, würde를 썼어요 ; 반대쪽 생각을 한 번 적었어요

-- sprich Meine Meinung | 주제는 '숙제가 필요할까?'예요. 아래 낱말을 보면서 1분쯤 내 의견을 말하세요. 먼저 혼자 말해 보고, 그다음에 예시를 확인해요.
thema: dafür / dagegen ; Erstens … ; Zweitens … ; Die anderen sagen … ; Deswegen …
muster: Brauchen wir Hausaufgaben? Ich bin dafür, aber es sollten weniger sein. Erstens kann man zu Hause in Ruhe üben. Je öfter ich übe, desto besser verstehe ich das Thema. Zweitens sieht die Lehrerin, wer noch Hilfe braucht. Die anderen sagen, dass man nach der Schule müde ist. Das stimmt. Deswegen sollten Hausaufgaben nicht länger als eine halbe Stunde dauern.
