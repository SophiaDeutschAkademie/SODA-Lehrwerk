# 독일어 모의고사 난이도 측정 기준 (Goethe·telc A2–C1)

작성: 2026-11-19 · 측정 도구 `claude/difficulty-dm.py` (dm.py) · 대상: SODA Modelltest 전 시리즈

## 1. 원칙

1. **한 가지 도구, 한 가지 규칙으로만 비교합니다.** 모든 수치는 dm.py로 잰 값입니다. 시리즈별 기존 도구(telc C1 `check.py`, telc B1/B2 `lix.py` 등)와는 문장 경계·제목 처리 규칙이 달라 같은 텍스트도 1–3점 차이가 납니다. 기준값과 비교할 때는 반드시 dm.py 값을 씁니다.
2. **기준은 실제 시험 원문에서 나옵니다.** 공식 Modellsatz/Übungstest와 출판사 모의고사(Klett, Hueber, Cornelsen 등)를 영역별로 잰 중앙값과 범위가 기준입니다.
3. **"어렵지만 그 레벨 안"의 정의:** 각 지표가 **참고 자료 중앙값 이상, 참고 자료 최댓값 이하**이고, 영역 전체(Lesen gesamt)는 **다음 레벨 중앙값 미만**입니다. 참고 자료 범위가 2점보다 좁게 측정된 LIX와 > 5k %는 중앙값+2까지 허용합니다(표에 반영).
4. **한 지표만 맞추지 않습니다.** LIX가 맞아도 문장 길이·어휘·명사화의 조합이 실제 시험과 다르면 부자연스러운 텍스트가 됩니다(아래 4장 사례). 표의 지표가 함께 범위 안에 있어야 합니다.
5. **MTLD(어휘 다양성)는 상한 지표입니다.** 실제 시험보다 높으면 핵심어 반복이 적고 표현이 지나치게 다양한, 생성형 텍스트의 특징입니다.

## 2. 척도 (무엇을, 어떻게, 어느 방향으로)

| 척도 | 측정 내용 | 계산 | 어려워지는 방향 |
|---|---|---|---|
| **LIX** | 종합 가독성 | 단어/문장 + 7글자 이상 단어 % | ↑ |
| **WSTF** (1. Wiener Sachtextformel) | 독일어 전용 가독성, 독일 학년 수준(4–15) | 0,1935·MS + 0,1672·SL + 0,1297·IW − 0,0327·ES − 0,875 (MS 3음절 이상 %, SL 문장 길이, IW 7글자 이상 %, ES 1음절 %) | ↑ |
| FRE (Flesch-Amstad) | 보조 가독성 | 180 − 문장 길이 − 58,5·음절/단어 | ↓ (낮을수록 어려움) |
| **Satzlänge** (ASL) | 문장 길이 | 단어 수 / 문장 수 | ↑ |
| **Sätze > 25 %** | 긴 문장 비율 | 26단어 이상 문장 % | ↑ |
| **NS/Satz** | 문장 구조 복잡도 | 종속접속사(dass, weil, obwohl, nachdem …)와 쉼표 뒤 관계대명사 수 / 문장 수 | ↑ |
| **Nominal %** | 명사화 문체 | -ung, -heit, -keit, -ion, -ität, -nis, -schaft 등으로 끝나는 명사 % | ↑ |
| **> 5k %** | 어휘 빈도 | 독일어 빈도 상위 5000개 밖의 단어 % (보조: 2000개, 10000개) | ↑ |
| **MTLD** | 어휘 다양성 | 유형·토큰 비율이 0,72로 떨어질 때까지의 평균 단어 수(양방향) | 상한 지표: 실제 시험 최댓값 이하 |
| Passiv/100, Konj/100 | 문법 표지 | 100단어당 수동태(werden + 과거분사)·접속법(würde, hätte, sei …) | ↑ (근사치, 참고용) |
| **정답 겹침** | 문항의 패러프레이즈 정도 | 정답 선지(또는 richtig 진술)의 내용어 어간이 본문에 나오는 비율 | ↓ (낮을수록 바꿔 말함) |
| **오답 겹침** | 함정 강도 | 오답 선지의 같은 비율 | ↑ (본문 단어를 쓴 오답) |
| **키워드로 풀림 %** | 단어 맞추기로 풀리는 문항 | 정답이 본문과 겹침이 유일하게 가장 큰 MC 문항 % | ↓ |
| **정답=최장 %** | 응시 요령 단서 | 정답이 가장 긴 선지인 MC 문항 % | 단서 지표(낮게) |
| 발화 속도 | 듣기 속도 | 분당 단어 수(음원 길이 − 안내·쉼) | ↑ · 공식 음원 확보 후 기준 설정 |

측정 규칙: 단어 = 글자를 포함한 토큰(숫자만인 토큰 제외). 문장 끝 = . ! ? : … 뒤 공백, 줄바꿈, 문단 끝(제목·표 행도 한 문장). 약어(z. B., Dr., bzw. …), 날짜(4. November), 시각·숫자(8.30), 이니셜(Herr K.)은 문장을 나누지 않습니다. Sprachbausteine와 Textrekonstruktion은 정답을 넣고 잽니다. 듣기는 화자 표시와 시험 안내를 빼고 잽니다. 빈도 목록: FrequencyWords(OpenSubtitles 2018, 독일어 5만 단어, GitHub hermitdave/FrequencyWords `content/2018/de/de_50k.txt`).

## 6. 측정 결과에서 드러난 SODA 문제 (2026-11-19, 수정 전 상태)

1. **telc B2가 B2 범위를 넘었습니다.** 읽기 전체 LIX 50,9로 B2 최댓값 47,6을 넘어 C1 중앙값 51,0에 거의 닿습니다. 특히 SB1(편지)은 47,9로 실제 시험(32–37)보다 10점 이상 높습니다. 이전에 정한 목표(읽기 ≈ 50, SB ≈ 52)가 실제 시험보다 높았던 것이 원인입니다. 또 SB는 문장이 짧고(9–10단어) 드문 단어가 많아(> 5k 30 % 이상) 실제 시험(문장 12–15단어, 드문 단어 11–29 %)과 구성이 다릅니다.
2. **Goethe B2가 B1 공식 시험보다 쉽습니다(잠정).** 읽기 전체 LIX 38,1로 Goethe B1 참고 자료 중앙값(40,3)보다 낮습니다. Goethe B2 Modellsatz로 확인이 필요합니다.
3. **Goethe B1은 전 영역이 기준 하단보다 조금 낮습니다**(LIX 1–2점, 명사화 비율 낮음).
4. **Goethe A2 지문은 기준 구간 안(상단)이지만 문항은 공식보다 어렵습니다.** 정답 겹침 0,34(공식 0,62).
5. **telc C1은 LIX는 맞지만 방법이 다릅니다.** 실제 시험은 명사화(4,0 %)와 드문 어휘(29 %)로 어렵고, SODA는 긴 문장(17단어, 부문장 0,8)으로 어렵습니다. 다음 수정은 문장 길이보다 명사화·어휘 쪽으로 옮겨야 합니다.
6. **모든 시리즈의 MTLD가 실제 시험 최댓값을 넘습니다**(1,2–1,7배). 핵심 명사를 반복하고 지시어·대명사로 받는 실제 시험식 문체가 부족합니다.
7. **듣기는 SODA 값을 아직 재지 않았습니다**(대본이 PDF에만 있음). 참고로 telc B2 Leitfaden의 HV2 목표(LIX ≈ 45)는 실제 시험(27,8–37,7)보다 높습니다.

## 7. 사용 방법

1. 새 회차나 수정본은 dm.py로 영역별 값을 잽니다: `from dm import text_stats, item_stats` (빈도 목록 `de_50k.txt`를 같은 폴더에 두거나 `DM_FREQ` 환경변수로 지정).
2. 4장 표에서 해당 영역의 LIX, 문장 길이, > 5k %, 명사화가 모두 목표 구간 안인지, MTLD가 상한 이하인지 봅니다.
3. 문항은 정답 겹침이 기준 중앙값 이하, 오답 겹침이 정답 겹침 이상, 키워드로 풀림이 기준 중앙값 이하인지 봅니다.
4. 영역 전체 값이 다음 레벨 중앙값 미만인지 마지막으로 확인합니다.
5. 공식 자료가 새로 들어오면 참고 자료에 추가하고 표를 다시 계산합니다.
