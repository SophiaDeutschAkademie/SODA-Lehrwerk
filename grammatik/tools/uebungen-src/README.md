# 연습 챕터 원본 쓰는 법

`U01.json` … `U37.json`은 교재 Lektion 01 … 37에 하나씩 짝이 되는 연습 챕터의 원본이에요.
`python3 grammatik/tools/uebungen-build.py`가 이 파일들을 검사하고 `grammatik/uebungen/`의 앱용 파일로 만들어요.

## 파일 형식

```json
{
  "n": "05",
  "level": "A1",
  "goals": ["규칙 동사의 인칭어미를 붙여요", "모음이 바뀌는 동사를 구별해요", "…"],
  "items": [
    {"lv": 1, "t": "mc",    "q": "Du ___ gern Tee.", "o": ["trinkst", "trinke", "trinkt", "trinken"], "a": 0, "e": "du → 어간 + st."},
    {"lv": 1, "t": "fill",  "q": "Er ___ jeden Tag Zeitung.", "ko": "그는 매일 신문을 읽어요.", "h": ["lesen"], "a": ["liest"], "e": "lesen은 e → ie, er·sie·es에서 모음이 바뀌어요."},
    {"lv": 2, "t": "order", "q": "단어를 알맞은 순서로 놓으세요.", "ko": "오늘 저녁에 나는 친구를 만나요.", "a": ["Heute Abend treffe ich eine Freundin."], "e": "…"}
  ]
}
```

| 필드 | 뜻 |
|---|---|
| `n` | 두 자리 번호 (파일 이름과 같아야 해요) |
| `level` | 이 문법의 CEFR 수준: A1·A2·B1·B2 |
| `goals` | "이 연습에서 확인할 것" 3~4줄. 해요체 (~해요) |
| `lv` | 난이도 1=기본 · 2=중간 · 3=도전 |
| `t` | `mc` 객관식 · `fill` 빈칸 쓰기 · `order` 단어 배열 |
| `q` | 질문. `___`은 빈칸, `**굵게**`, 줄바꿈은 `\n` |
| `o`, `a` (mc) | `o` 보기 3~4개(순서는 아무렇게나, 앱이 섞어요), `a` 정답 보기의 번호(0부터) |
| `a`, `h` (fill) | `a` 빈칸마다 정답 하나. 정답이 둘 이상이면 `["dem","einem"]`처럼 목록. `h` 빈칸마다 힌트(없으면 `""`). 빈칸이 하나면 문자열도 돼요 |
| `ko` (fill·order) | 문장의 한국어 뜻. 필수 |
| `a` (order) | 정답 문장 목록. 첫 문장이 대표 정답이고, 다른 정답은 같은 단어들로만 만들어요. 단어는 공백으로 나뉘고 문장부호는 단어에 붙여요 |
| `e` | 해설. 해요체. 왜 그 답인지 한두 줄 |
| `ok` | (선택) 검사기 경고를 넘길 때 이유를 적어요 |

## 챕터의 구성

- 한 챕터에 30문항이 목표예요: 기본(lv 1) 16 · 중간(lv 2) 8 · 도전(lv 3) 6. 검사기 허용 범위는 합계 28~34, 기본 14~18, 중간 6~10, 도전 4~8이에요.
- 유형은 `mc` 10개 안팎 · `fill` 12개 안팎 · `order` 3~6개를 섞어요. 어순·문장틀이 핵심인 과는 `order`를 더 늘려도 돼요. 형태 변화(어미·활용)가 핵심인 과는 `fill`을 늘려요.
- 기본: 교재 표와 규칙을 그대로 쓰는 문제. 중간: 규칙 두 개를 함께 쓰거나, 문장 전체를 보고 골라야 하는 문제. 도전: 예외·함정·여러 규칙이 겹치는 문제, 틀린 문장 고르기, 문장을 바꿔 쓰기, 짧은 글 속 빈칸 같은 문제. 도전 문제는 정말 어려워야 해요(원어민도 잠깐 생각할 정도). 단, 아직 배우지 않은 문법은 어려움을 위해서도 쓰지 않아요.
- 같은 답이 계속 `a)`에 오지 않도록 신경 쓰지 않아도 돼요. 빌드가 보기를 섞어요.

## 지켜야 할 규칙

1. **배운 범위 안에서만.** Lektion N의 문항은 1~N과에서 배운 문법만 써요. 아직 배우지 않은 문법(시제·어순·격·접속사·화법조동사 등)이 문장에 들어가면 안 돼요. 교재 목차는 `python3 grammatik/tools/uebungen-check.py --toc`, 본문은 `--text N`으로 봐요. 아래 "초반 과의 함정"도 확인하세요.
2. **교재의 표현을 피해요.** 교재 1~37과(부록 포함)에 나온 문장과 표현은 그대로 쓰지 않아요. 새 어휘와 새 상황으로 만들어요. 검사기가 같은 문장은 오류로, 이어진 낱말 3~4개가 겹치면 경고로 알려 줘요.
3. **문법의 수준에 맞춰요.** 어휘와 문장 길이는 `level`에 맞춰요. A1은 짧고 일상적인 문장(최대 10단어쯤), A2는 조금 길고, B1·B2는 글에서 볼 법한 문장도 돼요. 아무리 어려운 도전 문제도 그 과의 `level`에서 크게 벗어나는 어려운 어휘를 쓰지 않아요.
4. **빈칸은 정답이 하나로 정해져야 해요.** 문장과 한국어 뜻, 힌트(`h`)를 보면 정답이 하나로 정해져야 해요. 다른 답도 문법상 맞으면 `a`에 모두 넣어요. 동사 활용 빈칸은 힌트에 원형을 줘요. 전치사·관사 빈칸은 힌트에 명사와 성, 필요하면 뜻을 줘요(예: `"Hund · 남성"`).
5. **객관식 보기는 비슷하게 그럴듯해야 해요.** 학생이 실제로 하는 실수를 보기로 써요. "모두 맞다", "위의 둘 다", "정답 없음" 같은 보기는 쓰지 않아요.
6. **독일어는 정확해야 해요.** 자연스러운 현대 표준 독일어만 써요. 확신이 서지 않는 표현은 쓰지 않아요. `Was machst du von Beruf?`는 쓰지 않아요.
7. **한국어는 해요체로 써요.** (~해요, ~예요). 반말(~다)과 격식체(~습니다)는 쓰지 않아요. 군더더기와 비유 없이 직접 서술해요.
8. **한 챕터 안에서, 그리고 챕터끼리 같은 문장이 반복되지 않게 해요.** 같은 명사·동사가 반복돼도 문장은 달라야 해요.
9. 독일 국기 색(빨강·노랑) 이야기, 국기 모양 같은 장식 요소는 쓰지 않아요.

## 초반 과의 함정 (이 과에서 아직 배우지 않은 것)

- 1~2과: 4격 남성형(den·einen·keinen)은 3과에서 배워요. 목적어 자리에 남성 명사를 쓰지 않아요. 주어·보어(`Das ist`, `Ich bin`, `Da ist`) 자리의 남성은 괜찮아요. 3격도 3과 전에는 쓰지 않아요(복수 3격 -n은 2과에서 다루는 것만).
- 1~4과: 동사는 `sein`, `haben`과 규칙 동사의 ich·wir·sie(복수) 형태 위주로 써요. er·sie·es 형태는 규칙 동사(-t)만 써요. 모음이 바뀌는 동사(sehen·lesen·geben 등)의 er 형태와 du 형태는 5과에서 배워요. 교재 1~4과 본문에 이미 나온 형태는 써도 돼요.
- 1~5과: 의문사 의문문과 어순 바꾸기(부사를 문장 앞에 놓기)는 6과에서 배워요. 이 과들에서는 `Wo ist …?`처럼 교재 본문에 나온 틀만 써요.
- 1~6과: 숫자 1–10은 2과부터 괜찮고, 11 이상·날짜·요일·시각은 7과 이후에 써요.
- 1~8과: 소유관사(mein·dein 등)는 8과에서, `kein`·`nicht`은 9과에서 배워요.
- 1~9과: 화법조동사(können·müssen 등과 möchte)는 10과에서 배워요. 10과 전에는 `Ich möchte …` 같은 문형도 쓰지 않아요.
- `und`는 어느 과에서나 괜찮고, `oder`·`aber`·`denn` 같은 접속사는 해당 과(19과)에서 배워요. 6~9과에서는 교재 본문에 나온 쓰임만 써요.
- 전치사는 14과에서 정식으로 배우지만 `in Berlin`, `aus Korea`, `mit dir` 같은 교재 본문에 나온 틀은 그 과 이후에 써도 돼요. 새 전치사 틀을 쓸 때는 교재 본문에서 이미 나왔는지 확인해요.
- 일반 규칙: 문장에 쓴 모든 문법이 교재 본문 N과 이하에 나와 있는지 확인해요. 이 기준이 가장 정확해요.

## 앱이 답을 채점하는 방식

- 빈칸(`fill`)은 대문자·소문자를 구별하지 않고, `ä·ö·ü·ß`를 `ae·oe·ue·ss`로 쳐도 맞는 것으로 봐요. 문장부호와 앞뒤 공백도 무시해요. 따라서 이런 변형은 `a`에 따로 적지 않아요.
- 관사나 어미가 필요 없는 자리는 `["-","–","—"]`처럼 하이픈을 정답 목록으로 쓰고, 힌트에 "관사가 필요 없으면 -"라고 알려요.
- 줄임형이 맞는 답이 둘일 때(`im` / `in dem`)는 `["im","in dem"]`처럼 모두 적어요.
- 배열(`order`)도 대소문자를 구별하지 않아요. 단어는 `a[0]`을 공백으로 나눈 것이에요. 문장 앞 글자만 대문자인 탓에 힌트가 되지 않도록, 문장 첫 단어를 고르기 어렵게 문장을 만드세요.
- 배열 문제는 문장부호(. , ! ? ;)를 조각으로 주지 않고 채점에서도 무시해요. 문법상 가능한 어순은 모두 `a`에 적어요(첫 문장이 대표 정답). 같은 문장이 두 번 들어가면(문장부호·대소문자 무시) 검사기가 오류로 알려 줘요.
- `e`와 `q`에서 줄바꿈은 `<br>` 또는 `\n`을 써요. 다른 HTML은 쓰지 않아요.

## 힌트 쓰는 법 (빈칸)

- 동사 빈칸: 원형을 줘요 (`"gehen"`). 시제나 인칭은 문장에서 알 수 있어야 해요.
- 관사·어미 빈칸: 명사와 성을 줘요 (`"Hund · 남성"`). 격은 문장과 뜻으로 알 수 있어야 하고, 격 자체가 문제의 핵심이면 힌트에 쓰지 않아요.
- 전치사 뒤 관사 빈칸: `전치사 · 한국어 뜻 · 성` 형식으로 줘요 (`"mit · ~와 함께 · 남성"`).
- 힌트가 필요 없으면 `""`. 한국어 뜻(`ko`)이 있으니 문장의 뜻을 힌트에서 되풀이하지 않아요. 힌트는 짧게(괄호 안에 한 줄) 써요.

## 검사

```
python3 grammatik/tools/uebungen-check.py 05      # 05과만
python3 grammatik/tools/uebungen-check.py         # 전부
```

- **오류**는 반드시 고쳐요. 오류가 있으면 빌드가 그 챕터를 만들지 않아요.
- **경고**는 하나씩 확인해요. 정말 괜찮으면 그 문항에 `"ok": "이유"`를 적어요(예: `"ok": "werden은 본동사, 5과에서 배움"`). 이유 없이 `ok`를 붙이지 않아요.
- `[미학습 문법?]` 경고는 단순 패턴 검사라서 놓치는 것도 많아요. 검사를 통과해도 위 규칙 1은 직접 확인해요.

## 보강 문제 (`plus`)

과마다 기본·중간·도전 다음에 「보강」 구역이 있어요. 원본의 `items` 뒤에 `plus` 목록으로 적어요. 바꿔 쓰기와 오류 찾기를 2개 이상씩, 모두 4~8개(지금은 3 + 3).

```json
"plus": [
  {"t": "tr",  "q": "현재완료로 바꿔 쓰세요.", "s": "Ich kaufe ein Fahrrad.", "a": ["Ich habe ein Fahrrad gekauft."], "e": "…"},
  {"t": "err", "q": "Ich habe nach Berlin geflogen.", "x": 1, "r": "Ich bin nach Berlin geflogen.", "ko": "나는 베를린으로 비행기를 타고 갔어요.", "e": "…"}
]
```

| 필드 | 뜻 |
|---|---|
| `tr` 바꿔 쓰기 | `q` 한국어 지시문, `s` 바꿀 문장, `a` 정답 문장 목록(가능한 답을 모두), `ko`(선택) |
| `err` 오류 찾기 | `q` 틀린 단어가 하나 있는 문장, `x` 틀린 단어의 번호(공백으로 나눈 단어, 0부터), `r` 고친 문장, `ko` 뜻 |

- 바꿔 쓰기는 대소문자, `ä·ö·ü·ß` 표기, 쉼표·마침표 같은 문장부호를 무시하고 채점해요.
- 오류 찾기의 `r`은 `q`와 단어 수가 같고 `x`번째 단어 하나만 달라야 해요. 어순 오류처럼 두 단어가 바뀌는 문제는 만들지 않아요.
- 문법상 맞는 다른 해석이 있는 문장(예: `sich an etwas freuen`)은 오류 찾기에 쓰지 않아요.
- 보강 문항은 기존 문항 뒤에 번호가 이어져요. 기존 문항의 번호와 보기 순서는 바뀌지 않아요.

## 통합 복습 (`W1.json` …)

여러 과를 섞은 세트예요. 연습 목차 맨 아래 「통합 복습」에 나오고 주소는 `#/W1`이에요.

```json
{"n": "W1", "range": [1, 11], "level": "A1", "ko": "통합 복습 1", "de": "Wiederholung 1 · Lektion 01–11",
 "goals": ["…", "…", "…"], "items": [ … ]}
```

- `items`에는 `mc`·`fill`·`order`·`tr`·`err`를 모두 쓸 수 있어요. 16~30문항, 기본·중간·도전이 모두 있어야 해요.
- `range`의 마지막 과까지 배운 문법만 써요. 해설 끝에 관련 과를 `(10과)`처럼 적어요.

## 학생 기록을 지키는 규칙

- 앱은 학생이 푼 답을 그 기기의 `localStorage` 키 `sda-lehrwerk-grammatik-ueb-v1`에 저장해요. 새로고침, Teams·카카오톡 안의 브라우저, 앱 업데이트 뒤에도 답이 남아요. 교재 진도 기록(`sda-lehrwerk-grammatik-v1`)과는 따로 저장돼요.
- 답은 문항마다 붙는 고정 번호(`data-id`)로 저장해요. 번호는 질문과 정답으로 만들어지므로 문항을 더하거나 순서를 바꿔도 다른 문항의 답이 섞이지 않아요. 문항의 질문·정답을 고치면 그 문항의 이전 답만 사라져요. 해설·힌트만 고치면 답이 그대로 남아요.
- 두 키의 이름과 형식(`v: 1`)은 바꾸지 않아요. 바꾸면 모든 학생의 기록이 사라져요.
