# SODA Modelltest (옛 주소 안내)

Goethe와 telc 모의고사(Modelltest)는 용량 한도(GitHub Pages 1 GB) 때문에 별도 저장소로 옮겼습니다. 이 폴더에는 옛 주소를 새 주소로 넘기는 안내 페이지(`index.html`, `digital.html`)만 남아 있어요. 북마크해 둔 주소는 그대로 새 주소로 이어집니다(`#1-lesen` 같은 뒷부분도 유지).

| 모의고사 | 새 저장소 | 새 주소 |
|---|---|---|
| Goethe A2, B1, B2 | `SODA-Goethe` | https://sophiadeutschakademie.github.io/SODA-Goethe/ |
| telc B1, B2, C1 Hochschule | `SODA-TELC` | https://sophiadeutschakademie.github.io/SODA-TELC/ |

앱 폴더 구성, 다시 만드는 방법, 새 Modelltest 추가 방법은 각 저장소의 README와 앱 폴더의 `digital-src/README.md`에 있습니다. 메인 목차(루트 `index.html`)의 「SODA Modelltest」 타일은 위 새 주소로 연결됩니다.

학생의 답과 결과, 다크 모드 선택은 브라우저의 같은 주소(`sophiadeutschakademie.github.io`) 아래에 저장되므로 저장소를 옮긴 뒤에도 그대로 이어집니다. 사용자 지정 도메인으로 바꾸면 이 연결이 끊어질 수 있어요.
